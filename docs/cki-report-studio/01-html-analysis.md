## 3. Проблемы текущего HTML (зачем нужен продукт)

1. **Дублирование данных** — одно число правится в 3–6 местах.
2. **Вычисляемые поля вручную** — %, progress width, ▲/▼, цвета, Σ воронки, Δ команды.
3. **Статический SVG** — правка координат = источник ошибок.
4. **Рассинхрон дат** — имя файла 23.07, титул «16 июля», активности с 20.07.
5. **Нет схемы** — любой сотрудник правит «на глаз».
6. **Нет истории** — предыдущие недели не версионируются как данные.

## 5. Вывод Этапа 1

HTML — презентационный deck из **7 слайдов** с ~**90+ ручными точками правки**, из которых ~**40% вычисляемые** и ~**25% дубли**.

Продукт должен:

1. Хранить только **исходные** значения.
2. Автоматически считать derived.
3. Рендерить HTML из шаблона + JSON.
4. Заменить SVG-графики на data-driven charts.
