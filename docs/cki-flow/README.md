## Что это

**CKI Flow** — специализированная система планирования и исполнения продуктовой разработки команды ЦКИ.  
Не аналог Jira. Не цифровая копия физической доски.  

Источник истины — **модель объектов и связей**. Доска, roadmap, backlog, capacity view — только представления одних и тех же данных.

Цель продукта: сделать управление **кварталом, спринтами и бэклогом** быстрым, прозрачным и предсказуемым — с автоматическими зависимостями, capacity planning и контролем рисков.

## Ключевое архитектурное решение (кратко)

**Выбрана модель: Object Graph + Orthogonal Timeboxes + Process Templates.**

- Иерархия ценности: `Product → Quarter Goal → Initiative → Epic → User Story → Work Item`
- Ортогональные измерения: `Sprint`, `Release`, `Team/Role Capacity` — не уровни иерархии
- User Story — центральный объект поставки
- Работы создаются из **шаблонов процессов**, а не вручную
- Зависимости — граф с автоматической валидацией и критическим путём
- Capacity — по **ролевым пулам** (BA / SA / BE / FE / QA / PM / UX / Arch), не только по людям

Подробное обоснование — в [10-alternatives-decision.md](./10-alternatives-decision.md).
