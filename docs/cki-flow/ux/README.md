# CKI Flow — UX Design

**Этап:** UX / Product Design  
**Статус:** проектирование интерфейса (без кода, HTML, CSS, React)  
**Платформа:** desktop macOS  
**Персона:** Product Manager (ежедневная работа ~8 часов)  
**База:** [архитектура](../README.md) · [Domain Model](../domain/README.md)  
**Дата:** 2026-08-05

---

## Назначение

Законченный UX-проект приложения CKI Flow — основа последующей реализации.

Интерфейс проектируется как **рабочее место PM**, а не как CRM, не как Jira и не как набор форм.  
Все экраны — **проекции Domain Model**; доска/roadmap не хранят отдельную истину.

## Одно предложение про продукт

> CKI Flow — это быстрый «пульт управления кварталом»: сигналы → решение → действие с клавиатуры, а не бесконечное заполнение тикетов.
